Tidy the code. This is the action for you.

Review the relevant code and improve it without changing package behavior.

Good tidy work includes:

- removing dead, duplicate, or unnecessary code
- simplifying names, control flow, and file structure when the result is clearer
- refactoring behavior-preserving code paths
- tightening tests or checks when they are directly related to the cleanup
- leaving unrelated features and broad rewrites alone

Keep the scope focused. Do not introduce package features during a tidy pass.

Before finishing, run the relevant tests or checks for the files you touched.
