# Git commits

Use imperative mood and use a prefix for the type of change.

Examples:

```text
feat(node): add typed child creation
fix(sync): reject duplicate operations
ci: update release workflow
docs: update README
deps: update vitest
dev: add benchmark helper
```

Commit types:

- package feature: `feat(name): description`
- package fix: `fix(name): description`
- build or release work: `ci: description`
- tests: `tests: description`
- documentation: `docs: description`
- dependencies: `deps: description`
- developer convenience: `dev: description`
